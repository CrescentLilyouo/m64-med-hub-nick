## 一、疾病定義與閱讀目標
糖尿病酮酸中毒（diabetic ketoacidosis，DKA）是胰島素作用不足所造成的急性代謝失衡，核心是「酮體增加與代謝性酸中毒」，常伴高血糖、脫水和電解質缺失。它不是只看血糖高低的診斷，也不是第一型糖尿病的專屬併發症。第二型糖尿病在嚴重感染、重大急症或特定藥物背景下，同樣可能發生。
讀這一章時，要能解釋四件事：為什麼酸中毒、為什麼血鉀可能高但全身缺鉀、為什麼血糖下降後仍須胰島素，以及為什麼治療需要同步尋找誘因。這四個問題串起機轉、檢查、治療與國考情境。
本章以成人為範圍。兒童的補液、腦損傷風險與胰島素安排有專門流程；孕婦及透析病人也需要個別策略，不把成人一般架構直接套用。
## 二、病生理：從胰島素不足連到每一個症狀
### 高血糖與脫水如何形成
胰島素不足使周邊組織利用葡萄糖下降，升糖素、兒茶酚胺、皮質醇及生長激素等反調節激素又促進肝臟糖質新生與肝醣分解。血糖升高超過腎臟再吸收能力後，葡萄糖出現在尿中，帶走水與電解質，形成滲透性利尿。
病人先出現多尿、口渴，再因水分補充不足、噁心嘔吐與持續尿液流失而脱水。有效循環量下降使腎灌流變差，葡萄糖及酮體清除下降，進一步加重失衡。因此補液本身就能改善血糖與循環，並非只有胰島素才有作用。
### 酮體與酸中毒如何形成
缺乏胰島素的抑制作用後，脂肪組織分解三酸甘油酯，游離脂肪酸進入肝臟形成酮體。β-hydroxybutyrate（BHB）與 acetoacetate 增加，消耗緩衝系統，形成高陰離子間隙代謝性酸中毒。Acetone 可造成特殊呼氣味，但沒有氣味不能排除。
酸中毒刺激深而大的代償呼吸，稱為 Kussmaul breathing；這是代謝性酸中毒的呼吸代償，不代表原發肺病。若原本深快的呼吸轉為疲弱，須警覺呼吸肌疲乏或意識惡化。
| 變化 | 原因 | 對症狀與判讀的意義 |
| 多尿與口渴 | 高糖造成滲透性利尿 | 尿量多不代表循環水分充足 |
| 心搏過速、低血壓 | 容量不足與應激 | 應同時檢查循環及誘因 |
| 深大呼吸 | 對代謝性酸中毒的代償 | 不能只當作焦慮過度換氣 |
| 腹痛、噁心、嘔吐 | 酸中毒與代謝失衡等 | 若矯正後仍腹痛，要重新找腹部病因 |
| 意識改變 | 脫水、滲透壓、酸中毒或併存疾病 | 不要求昏迷才可診斷 DKA |
### 血鉀與全身鉀庫存為何方向不同
全身鉀因尿液與嘔吐流失而下降，但胰島素不足、酸鹼及滲透變化使鉀往細胞外移，因此抽血可能正常甚至偏高。開始胰島素、補液及矯正代謝失衡後，鉀進入細胞並增加腎臟排出，血鉀可迅速下降。
國考遇到「高血鉀的 DKA」，不能回答病人全身鉀過多，也不能認為治療期間不用再測鉀。血中濃度和身體總量是兩種不同資訊。
## 三、病因與誘發因素：找到為何在今天發作
| 誘因 | 病史與檢查線索 | 應避免的推論 |
| 感染 | 發燒、局部症狀、循環與器官功能變化 | 壓力性白血球增加本身不能證明細菌感染 |
| 胰島素中斷 | 漏打、經濟或取得困難、幫浦故障、錯誤停藥 | 不把所有中斷都簡化成病人不配合 |
| 初發糖尿病 | 多尿、體重減輕、近期口渴，先前未診斷 | 沒有糖尿病病史不能排除 |
| 心肌梗塞、腦中風等急症 | 胸部症狀、神經學缺損、相應檢查 | 高糖不應遮蔽另一個急症 |
| 藥物與特殊情境 | SGLT2 inhibitor、禁食、手術、妊娠等 | 血糖沒有很高仍可能存在酮酸中毒 |
| 反覆發作 | 自我照護、憂鬱、飲食疾患、支持系統與藥物供應 | 只調一次胰島素劑量未必能防止復發 |
病因調查與急性治療並行。發燒缺乏或病人不能陳述症狀，不等於沒有感染；相反地，也不能只因白血球高就忽略缺血、胰臟炎、藥物或治療中斷。
## 四、診斷：先看三個構成，再看嚴重度
### 現行成人定義與舊講義的差異
2024 年成人高血糖危象共識將 DKA 以三組條件界定，三組都需成立。以下表格是本章的版本更新摘要；舊講義使用的血糖 250 mg/dL、HCO₃ 15 mmol/L 等數值，不能不加辨別地當作現行必要条件。
| 構成 | 2024 成人共識條件 | 如何理解 |
| 糖尿病或高血糖 | 血糖 ≥200 mg/dL，或已有糖尿病病史 | 已知糖尿病者不必靠非常高的血糖才能成立 |
| 酮體 | BHB ≥3 mmol/L，或尿酮 ≥2+ | 直接血中 BHB 更接近主要代謝變化 |
| 酸中毒 | pH <7.3，和／或 HCO₃ <18 mmol/L | 必須將酮體與酸鹼一起判斷 |
### Euglycemic DKA
已有糖尿病、使用 SGLT2 inhibitor 或特定禁食及妊娠背景者，可能有酮酸中毒但血糖沒有明顯升高。SGLT2 抑制腎臟葡萄糖再吸收，增加尿糖流失，血糖數字因此不一定反映酮體負荷。題幹若有腹痛、深快呼吸、低 HCO₃ 與相關背景，仍應檢查血酮與酸鹼。
### 嚴重度與照護地點
嚴重度不是用「血糖越高越重」排序，還要看酸中毒程度、酮體、意識、循環與併存急症。輕度且單純的病例與休克、重度酸中毒或意識障礙者，需要的監測資源不同。分類工具不能取代病人的整體狀態。
## 五、檢查與數值判讀
### 初始檢查各自解答什麼問題
| 檢查 | 要回答的問題 | 限制與陷阱 |
| 血糖 | 高血糖程度與後續下降趋势 | 不能單獨代表酸中毒已改善 |
| Na、K、Cl、HCO₃、腎功能 | 水分、電解質、陰離子間隙、腎臟清除 | 正常血鉀不能排除全身缺鉀 |
| 靜脈血氣 | pH 與酸鹼狀態 | 若有重要氧合或呼吸問題，還需適合的呼吸評估 |
| 血中 BHB | 直接評估酮體 | 設備、採樣與追蹤方法須一致 |
| 尿酮 | 無血酮資源時提供線索 | Nitroprusside 法主要測 acetoacetate，非主要 BHB |
| ECG | 鉀相關變化或缺血線索 | ECG 正常不能保證鉀安全 |
| 依情境採檢與影像 | 感染、缺血或其他誘因 | 不為了固定全套檢查延誤循環處理 |
### Anion gap、代償與混合酸鹼問題
常用公式為 AG = Na −（Cl + HCO₃）；有些實驗室公式含 K，參考值不同，應先確認定義。白蛋白是重要未測陰離子，低白蛋白可能使 AG 看來不高，不能忽略背景。
Winter 公式可估計代謝性酸中毒的呼吸代償：預期 PaCO₂ 約為 1.5 × HCO₃ + 8 ±2 mmHg。實際 CO₂ 高於預期，考慮合併呼吸性酸中毒；低於預期，考慮另有呼吸性鹼中毒。嘔吐可能合併代謝性鹼中毒，敗血症也可能引起其他酸鹼變化，所以一次接近正常的 pH 不保證只有正常代謝。
### 為何治療後尿酮可能看起來更高
DKA 時 BHB 比例高，治療後 BHB 可轉為 acetoacetate，而尿酮方法較容易測到後者。因此尿酮可能持續陽性，甚至看似增加。不能只凭尿酮顏色決定治療失敗，也不能以尿酮完全陰性作為唯一停藥條件。
## 六、鑑別診斷：有酮或酸不等於 DKA
| 情境 | 相似處 | 區分方法 |
| 飢餓性酮症 | 禁食、酮體升高 | 糖尿病背景、酸中毒程度與攝食病史；嚴重情境仍須完整評估 |
| 酒精性酮酸中毒 | 嘔吐、AG 上升與酮體 | 酒精與進食中斷病史，血糖未必高；可與其他問題並存 |
| 乳酸性酸中毒 | HCO₃ 低、AG 增加 | 循環、缺氧、感染與 lactate，不能用尿酮單獨區分 |
| HHS | 高糖、脫水、神經症狀 | 滲透壓與是否達酮酸條件；可為混合型 |
| 腎衰竭或毒物 | 高 AG 酸中毒 | 腎功能、暴露與特定檢驗；依病史選擇 |
DKA 可以和乳酸升高、AKI 或 HHS 同時存在。鑑別的目的不是強迫每位病人只能得到一個標籤，而是確認有哪些機轉需要一起處理。
## 七、治療：每一項措施都有不同目的
### 先穩定循環，並評估鉀是否允許給胰島素
先評估呼吸、意識、循環、容量與尿量，建立靜脈通路、取得必要檢體並安排持續追蹤。補液改善腎灌流與容量缺失；胰島素主要停止酮體生成、恢復代謝；補鉀預防治療後危險低血鉀；誘因治療避免失衡持續。
這些措施常同步進行，但「補鉀與胰島素的關係」有關鍵先後。依 2024 成人共識，K <3.5 mmol/L 時先補鉀，延後胰島素至鉀回到安全範圍；舊題常見門檻為 3.3，應辨別題目版本。鉀較高者也需追蹤，不能認為永遠不會缺鉀。
### 液體選擇與個別化
成人補液可採等張鹽水或合適的平衡晶體液，速度依容量、循環與共病。大量氯離子輸入可造成非 AG 的高氯性酸中毒，因此後續 HCO₃ 不正常，未必全是持續酮酸。
心衰竭、年長衰弱、嚴重腎病或透析者，不能按一般病人缺水量機械補完。需要反覆檢查肺部、氧合、血壓、尿量與容量狀態。透析者甚至未必具有一般 DKA 的尿液電解質流失模式。
### 胰島素與加葡萄糖的理由
靜脈短效胰島素便於在急性期調整；具有監測條件的部分單純輕中度病例，也可能採皮下注射速效胰島素流程。重度酸中毒、休克或複雜病例不能直接套用較簡化方式。
成人常用固定速率靜脈短效胰島素 0.1 units/kg/h；依 2024 共識，血糖低於 250 mg/dL 時配合葡萄糖，並可將速率調整至約 0.05 units/kg/h，持續到酮酸解除。這些用量須在鉀安全、可密切監測的條件下使用；不能把每公斤速率誤寫成每位病人的固定總量。輕症皮下流程需另有規範，不能把相同數字直接改成偶爾打一針。
血糖下降通常早於酮酸中毒完全解除。適當時加葡萄糖液，目的是讓胰島素能繼續抑制酮體，同時避免低血糖。加糖不是治療方向反轉，而是「治療酮酸」與「維持安全血糖」要一起達成。
| 處置 | 主要目的 | 不能忽略的監測 |
| 晶體液 | 恢復循環與腎灌流 | 容量過多、Na 與腎功能 |
| 胰島素 | 停止酮體生成與降低血糖 | K、血糖與酸中毒趋势 |
| 鉀補充 | 修補缺失、避免治療後低鉀 | 腎功能、尿量、ECG 與重複血鉀 |
| 葡萄糖液 | 允許持續抑酮治療 | 血糖、液體與電解質負荷 |
| 誘因處理 | 控制感染、缺血或治療中斷等 | 原發急症與再發風險 |
### Bicarbonate 與磷不是每人例行補充
多數病例靠液體及胰島素矯正酸中毒，不常規使用 bicarbonate；使用可能影響鉀及酸鹼，需要特定嚴重酸血症情境評估。磷也不是抽血低就一律大量補充，需看程度、呼吸肌或心肌功能及其他症狀，補充又可能造成低鈣。國考問「常規處置」時，要區別必要核心措施與特定情況才使用的措施。
2024 成人共識在 pH <7.0 的嚴重情況可考慮 bicarbonate；舊教材常用 <6.9，作答要確認版本。不是 pH 一低於正常就例行補鹼。
## 八、治療反應、解除標準與轉換
### 追蹤什麼，而不是只追一個血糖
治療期間反覆評估生命徵象、意識、輸入輸出、容量、血糖、K、腎功能及血酮／酸鹼。數值未按預期改善時，要找通路或輸注問題、誘因未控制、混合酸鹼、腎功能及診斷是否完整，而不是只加大胰島素。
一般成人急性期血糖常每 1–2 小時監測，電解質、腎功能、血酮與靜脈 pH 約每 4 小時追蹤；鉀在開始胰島素後約 2 小時需再確認，此後依變化更密切調整。監測間隔是最低架構，休克、低鉀或快速變化時不能等固定時間才重測。
2024 共識的 DKA 解除重點為 BHB <0.6 mmol/L，且 pH ≥7.3 或 HCO₃ ≥18 mmol/L；理想上血糖也低於 200 mg/dL。AG 可受高氯性酸中毒影響，尿酮又有轉換落差，兩者不宜作為唯一解除標準。
### 轉為皮下治療為何需要重疊
靜脈胰島素作用短，皮下胰島素起效需要時間。若立刻停掉靜脈輸注、稍後才給皮下藥物，中間可能出現作用空窗，造成血糖與酮體再升。轉換需安排適當重疊、進食與完整 basal／prandial 計畫；不能只保留臨時 sliding scale 而忽略基礎需求。
## 九、併發症、預後與預防再發
| 風險 | 發生理由 | 複習時要連結的觀念 |
| 低血糖 | 胰島素與葡萄糖供應失衡 | 血糖降下來後仍可能需要抑酮治療 |
| 低血鉀 | 原本缺鉀加上細胞內轉移 | 起始高鉀不能提供整段治療的安全保證 |
| 容量過多 | 補液與心腎承受能力不匹配 | 補液量應隨反覆評估調整 |
| 神經惡化 | 代謝、滲透變化或其他腦部疾病 | 不只歸因為疲倦或「原本就昏迷」 |
| 復發 | 誘因、供藥、幫浦或照護問題未改善 | 出院教育與取得治療同樣重要 |
出院前須回顧發作原因，教導生病時如何監测、何時量酮、如何處理食慾差與胰島素需求，並安排追蹤。第一型糖尿病者不能因沒吃飯就任意完全停止基礎胰島素。提供可執行的計畫，比單說「要規則吃藥」更能防止復發。
## 十、國考情境與推理練習
以下為依知識點自行設計的短情境，並非逐字轉載歷屆試題。
? 血糖 180 mg/dL，使用 SGLT2 inhibitor，腹痛、BHB 4.2、pH 7.22。能因血糖不到 250 排除 DKA 嗎？
! 不能。需要結合糖尿病背景、酮體和酸中毒，考慮 euglycemic DKA。題目關鍵是病理構成，而不是舊講義常見的單一血糖門檻。
? DKA 初始 K 5.4 mmol/L，是否代表全身鉀充足，因此整段治療都不需監测鉀？
! 不是。全身鉀常已因利尿而缺失，胰島素與代謝改善後血鉀會下降。起始濃度不能代表全身總量或後續安全性。
? 血糖已降至 190，但仍有明顯酮體與酸中毒，最重要的下一步觀念是什麼？
! 維持抑制酮體所需的胰島素，並配合適當葡萄糖及監測，而不是只看血糖正常就停掉治療。
? K 3.1 mmol/L 且酸中毒，應優先立即加大胰島素嗎？
! 先處理低鉀並暫緩胰島素，因胰島素會再把鉀移入細胞，可能誘發致命心律不整。這是處置先後題的重要安全點。
? 補液後 BHB 已下降，尿酮反而更明顯，是否必然表示病情惡化？
! 不一定。酮體種類轉換及檢測方法可造成落差，應看直接血酮、酸鹼與整體臨床反應。
? 代謝改善後腹痛仍持續，能一律解釋為 DKA 嗎？
! 不能。重新找胰臟炎、缺血、感染或其他腹部病因；誘因與併發症可能需要另外處理。
